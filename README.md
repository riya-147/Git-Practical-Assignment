## Purpose of the Repository

The purpose of this repository is to learn and demonstrate the basic concepts of Git and GitHub. It is used to practice creating a Git repository, tracking files, staging changes, committing changes, connecting a local repository to GitHub, and managing files using Git.



## Objectives of the Practical:

To understand the basics of Git and GitHub.
To create and initialize a Git repository.
To learn how to track files using Git.
To understand the staging and commit process.
To connect a local repository with GitHub.
To push files from a local repository to GitHub.
To clone a GitHub repository.
To modify, track, commit, and push changes.


## Git Commands Learned:

git --version – Check the installed Git version.
git config – Configure Git username and email.
git init – Initialize a Git repository.
git status – Check the current repository status.
git add – Add files to the staging area.
git commit – Save changes to the repository.
git log – View commit history.
git remote -v – View remote repository information.
git push – Upload changes to GitHub.
